# Architecture Decision Records (ADRs)

Short, numbered records of the decisions that shape this project — one file per
decision, never edited after acceptance (supersede with a new ADR instead).

The pipeline notebooks reference **ADR-0001, ADR-0002, ADR-0003** (e.g. "speckle
is expected output today", the shared-folder handoff convention). Those records
currently live in the Google Drive `Ortak` folder and should be **copied here** as
`0001-*.md`, `0002-*.md`, `0003-*.md` so the reasoning lives with the code.

## Format

```
# ADR-000N: <title>

- Status: accepted | superseded by ADR-XXXX
- Date: YYYY-MM-DD

## Context
What forced the decision.

## Decision
What we chose.

## Consequences
What this makes easy / hard, and what we accept as a result.
```
